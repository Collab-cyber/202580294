# Smart Travel Packing Dashboard
A smart travel web application that helps travelers pack efficiently by providing personalized packing recommendations based on real-time weather conditions. Users can create an account, search destinations worldwide, and receive an intelligent packing checklist before their trip.

# Project Planning

## Project Goal

Develop a responsive web application that allows users to:
- Create an account
- Log in securely
- Search any destination
- View live weather conditions
- Receive an automatic packing checklist
- Save and manage previous trips
