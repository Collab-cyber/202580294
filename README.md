## PalaTrip

PalaTrip is a simple travel guide website that helps users discover
popular tourist destinations and activities in Palawan.

## About the Website

The website focuses on different tourist destinations in Palawan.
Users can explore places, view destination information, and discover
activities they can do during their trip.

PalaTrip also includes a login, registration, and profile page where
users can view their basic information and travel history.

## Main Features

- Palawan tourist destinations
- Destination search
- Tourist activities
- Destination information
- Login page
- Registration page
- User profile
- Trip history

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Goal

The goal of PalaTrip is to provide a simple and user-friendly website
for people who want to explore tourist destinations and activities in Palawan.
